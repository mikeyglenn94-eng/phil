1. FITNESS SCORE POLISH
======================================

Problem:
The Fitness Score card can feel confusing when there are no sessions yet this week but the card still shows movement versus last week and last month.

Fix:
When the current week has no logged sessions yet, make the card clearly communicate that the score is carrying over from the previous state.

Rules:
- if no sessions logged in current week:
  - keep showing the current displayed Fitness Score
  - but label the state more clearly
  - do not make it feel like the score already changed because of this week
- use wording like:
  - “No sessions yet this week”
  - “Waiting for this week’s training”
  - “Score currently reflects recent training”

Adjust comparison copy so it feels coherent.
For example:
- main score stays visible
- comparison lines can remain, but the state message must make it obvious this is not driven by current-week activity yet

Do not remove weekly and monthly comparisons entirely.
Just make the meaning clearer.

======================================

Fix:

Rules:

4. CONSISTENCY CARD POLISH
======================================

Problem:
The consistency card feels too dead when it says things like “0/? sessions” and “No sessions logged yet this week”.

Fix:
Make it feel more useful and intentional.

Rules:
- if user has a formal plan:
  - show completed / planned clearly
  - examples:
    - “0 / 4 sessions”
    - subtitle:
      - “Week just getting started”
      - “No sessions logged yet”
      - “3 sessions remaining”
- if user has no formal plan:
  - do not show “?”
  - instead use a more useful fallback
  - examples:
    - “0 sessions this week”
    - subtitle:
      - “Last week: 3 sessions”
      - “Start your first session this week”
- if week has started but no sessions logged:
  - make wording gently forward-looking
- if all planned sessions completed:
  - use positive status copy
- if some planned sessions missed:
  - explain simply and clearly

Do not make the card feel punitive.
