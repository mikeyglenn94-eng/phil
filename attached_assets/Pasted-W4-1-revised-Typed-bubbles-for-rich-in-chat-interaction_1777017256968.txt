W4.1 (revised) — Typed bubbles for rich in-chat interactionsExtends the Wave 1 chip-first pattern with structurally distinct bubble types for content that can't be expressed as text-with-chips.Already handled by Wave 1, do not rebuild:

Simple chip responses (post-session feedback, confirmations, state-of-self) are already emitted as text messages with quickReplies. Do not create separate FeedbackPromptBubble or ConfirmBubble components.
New bubble types to build (these have custom layouts that chips can't express):
PlanPreviewBubble — horizontally scrollable 7-day card strip. Each card: day name, session type chip, session title, 2-3 key exercises. Inline chip row on the bubble: "Tweak", "Build full block", "Not yet". The chips use the Wave 1 QuickReplyChips component for consistency, but the preview content above them is custom.

QuickLogBubble — inline weight (number) and reps (number) inputs plus a "Log" button. Used when Phil asks for a quick in-chat log ("What did you hit on bench?"). On submit, persists to the associated session and Phil acknowledges.

RpeBubble — the 5-pill emoji selector (😌 6 / 🙂 7 / 😐 8 / 😬 9 / 🫠 10) as a standalone bubble for ad-hoc asks in chat ("How did that last set feel?"). Distinct from set-inline RPE in the logger.

SessionCardBubble — tappable card referencing a calendar session. Shows date, session type chip, title, "View session" affordance. Tap opens the session view.
