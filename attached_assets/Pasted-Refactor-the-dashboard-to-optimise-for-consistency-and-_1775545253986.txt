2. FITNESS SCORE LOGIC
======================================

Build the score so it prioritises consistency and adherence.

Use this conceptual weighting:
- 40% consistency / adherence
- 35% performance trend
- 25% balance / activity momentum

Implement the score as a weekly score, then smooth it before displaying.

A. CONSISTENCY / ADHERENCE COMPONENT (40%)
This should be the most important part.

Use:
- sessions completed vs planned sessions
- whether the user completed both lifting and running in the week, if both are part of their plan
- whether the user maintained their streak
- whether they had meaningful training activity across the week

Scoring ideas:
- 100% of planned sessions completed = strong positive contribution
- 75% = moderate positive
- 50% = neutral to slightly negative
- below 50% = negative
- bonus if both modalities were completed in the week when relevant
- bonus for maintaining a weekly adherence streak

If the user has no explicit plan:
- fall back to frequency-based consistency
- compare this week’s meaningful sessions with the user’s recent baseline

B. PERFORMANCE TREND COMPONENT (35%)
This should matter, but move more slowly than adherence.

Include:
- estimated 5K trend
- squat e1RM trend
- bench e1RM trend
- deadlift e1RM trend

Rules:
- use changes versus prior equivalent period
- use rolling trend where possible, not one isolated session
- use only available lifts the user actually trains
- do not punish users for missing lifts they do not do
- do not let one unexpected PR swing the whole score too much

C. BALANCE / ACTIVITY MOMENTUM COMPONENT (25%)
Reward balanced, ongoing training.

Include:
- total meaningful lift sessions this week
- total meaningful run sessions this week
- distance run trend
- volume lifted trend

This should act as a smaller supporting signal, not the main driver.

3. SMOOTHING AND GUARDRAILS
======================================

This is critical.

Implement guardrails so the score feels credible:

- cap weekly displayed movement so it does not swing too hard
- smooth raw score changes before display
- reward repeated good weeks more than one-off spikes
- do not overreact to one missed workout
- do not overreact to one PR or one hard run

Implementation suggestion:
- calculate raw weekly component scores
- combine them into a raw score
- apply exponential smoothing or weighted rolling smoothing
- then cap the visible week-to-week change to a sensible maximum

Suggested visible weekly cap:
- normally max +8 or -5 per week

10. FITNESS SCORE FORMULA BEHAVIOUR
======================================

Build the formula around adherence-first logic.

Suggested implementation approach:

Step 1:
Calculate component scores on a 0 to 100 basis:
- consistencyScore
- performanceTrendScore
- balanceScore

Step 2:
Combine them:
fitnessRaw =
  consistencyScore * 0.40 +
  performanceTrendScore * 0.35 +
  balanceScore * 0.25

Step 3:
Smooth the raw score against the previous displayed score

Step 4:
Apply weekly movement caps

Step 5:
Round to a clean display number

IMPORTANT:
The visible score should usually move modestly.
Repeated good weeks should compound.
One extreme session should not dominate.
