2. NUTRITION SCORING LOGIC
--------------------------------------------------

Create a weekly nutrition adherence score based on the last 7 days.

For each day:

logging_score:
- 1 if the user logged nutrition that day
- 0 if they did not

accuracy_score:
- if calories are within ±100 of target → 1.0
- if within ±200 → 0.8
- if within ±300 → 0.6
- if more than ±300 away → 0.3

Rules:
- if the user did not log that day, accuracy_score = 0
- if no calorie target exists, fall back to logging_score only
- if only partial nutrition logging exists, still count as logged for MVP

daily_score = logging_score * accuracy_score

weekly_nutrition_score = average of daily_score over the last 7 days
nutritionPercent = Math.round(weekly_nutrition_score * 100)

Also calculate:
- loggedDays = number of days logged in last 7
- closeDays = number of days within ±200 calories of target

If there are fewer than 7 days of available data, use available days for the calculation.
