Fix 2 — Highlight anchors to goal, not highest volume
Current behaviour: picks the exercise with the highest volume or best e1RM across the whole session regardless of goal.
Correct behaviour: if the user has a strength goal set, check if the session contains that exercise first. If it does, use it as the highlight. Only fall back to best e1RM if no goal-relevant exercise exists in the session.
tsfunction getShareHighlight(session, clientGoals) {
  // Extract goal-relevant exercise names from goals
  const strengthGoals = clientGoals
    .filter(g => g.metric && ['bench_e1rm', 'squat_e1rm', 'deadlift_e1rm'].includes(g.metric))
    .map(g => g.metric.replace('_e1rm', ''));

  // Check if session contains a goal-relevant exercise
  for (const goalExercise of strengthGoals) {
    const match = session.exercises.find(ex => 
      ex.name.toLowerCase().includes(goalExercise.toLowerCase())
    );
    if (match) {
      return getBestSet(match); // use this exercise
    }
  }

  // Fallback: best e1RM across all exercises
  return getBestSetAcrossSession(session);
}
So for an account with a bench 130kg goal, a session containing bench press always shows bench as the highlight even if squat volume is higher.
