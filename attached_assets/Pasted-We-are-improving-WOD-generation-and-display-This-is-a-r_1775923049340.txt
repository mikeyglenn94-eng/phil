2. FIX WOD GENERATION LOGIC (TIME ACCURACY)

Problem:
	•	User asked for 40 min workout
	•	System generated ~12–18 min workout

Solution:

Introduce time estimation before finalising workout

For generated WODs:
	•	Estimate time per movement:
	•	Bike Erg: ~10–15 cal/min depending on assumed moderate pace
	•	Bodyweight reps: ~20–40 sec per 10–15 reps
	•	Estimate time per round
	•	Multiply by rounds
	•	Add buy-in + cash-out

Then:

IF total time is outside ±20% of requested duration:
→ auto-adjust before showing preview

Adjustment hierarchy:
	1.	Increase/decrease bike calories
	2.	Adjust rounds (primary lever)
	3.	Adjust buy-in / cash-out
	4.	Adjust reps (only if needed)

Goal:
	•	40 min request → actual 30–45 min realistic finish window
